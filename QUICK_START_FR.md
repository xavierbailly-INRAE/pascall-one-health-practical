# Démarrage enseignant — Pascall v1.2

Séance de 60 minutes, installation préalable. Ouvrir le projet RStudio du dossier étudiant puis exécuter :

```r
source("00_install_check.R")
source("RUN_R_CHECKS.R")
```

Attendre READY et lire les éventuels avertissements. Le parcours natif est désormais exécuté et validé sur Linux.
Pendant la séance, lancer un bloc complet de Pascall_student.R à la fois.
Le cache natif validé est inclus ; aucun secours n’est lancé automatiquement.

Pour le parcours navigateur : https://xavierbailly-inrae.github.io/pascall-one-health-practical/
Les étudiants suivent les cinq onglets et exportent leurs notes. Le navigateur recalcule les OLS,
mais montre des racines Python et des figures publiées ; il ne réalise pas les calculs R de datation.

Les neuf segments du TP et la date originale invalide sont documentés et conservés.
Le dossier enseignant contient les corrigés et reste distinct du dépôt public étudiant.
