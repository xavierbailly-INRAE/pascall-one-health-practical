# Pascall v1.2 — état de livraison

12 novembre 2026. Parcours R natif exécuté sur Linux : 13 contrôles structurels, deux contrôles d’arbres datés et 24 contrôles du harnais supplémentaires. Les deux racines, les secours natif/référence, les extensions et les cas d’échec sont testés. Le cache R validé est inclus.

Le HTML reste un parcours de référence autonome : OLS recalculées en JavaScript, racines Python et figures BEAST publiées explicitement identifiées. Notes sauvegardées localement quand autorisé et exportables.

La préparation v1.1 n’avait pas exécuté R ; ses rapports sont conservés sous validation/preparation_v1.1 dans le dossier étudiant. Ils décrivent la version historique.
